# 两个材料案例：新手引导与模拟演示指南

> 这两个案例现在是**首次启动的新手引导**：按 ① HCI 课件 → ② 控制作业 的顺序，每个案例走完「采用大纲 → 完成一小步 → 保存一块回顾」三步，两个都完成后点「开始正式使用」，首页才进入自己的学习任务，演示材料收进「我的任务 / 新手教程案例」。引导期间页面上有高亮框 + 气泡指出当前该点的按钮；也可以「跳过引导，直接使用」。引导进度保存在本地数据里；设置 → 新手引导 →「重新走一遍新手引导」只重置引导状态，不删除任务与回顾。

当前为 **2.4.0 模拟版**：不调用 API、不需要密钥。即使本机已有密钥，主进程也会阻断真实请求。生成、整理和缩小步骤均标注为模拟建议，用户自行确认。

## 学习 HCI 课件

1. 首页选择“学习 HCI 课件”，填写目标；可先看原文，再返回模拟拆解。
2. 查看七块大纲：用户分群、Persona、场景与故事板、任务分析与用例、HTA、时序图与认知走查、需求类型与表达。导读并入第一块，总结并入最后一块，覆盖97页。
3. 展开可改标题、目标、检验方式和首步，也可排序、合并。选择本次从哪块开始，采用大纲后只开始这一块。
4. 建议演示 HTA：原文打开 PDF 第61页，可前后翻页或输入页码。系统使用 PDF 文件页码，课件页脚编号可能不同。
5. 左侧保留总目标、本块目标、当前小步与检验方式。可以改小步、再拆小、自己标记完成，或暂停留点。
6. 点击“本块先到这里，回顾一下”，先写自己的解释和疑问，再可选模拟整理。候选不覆盖原话，采用后仍要自己保存；下一步另行加入计划。
7. 选择下一块不会自动开始；其他板块仍为待办。回顾状态不表示掌握，重复进入后跳过也不会清掉已有回顾。

## 梳理自动控制作业

1. 首页选择 Homework 7，模拟拆成六阶段：核对要求、前置知识自检、第一题整定与验证、第二题设计与验证、第三题绘图对比、提交检查。
2. “题目明确要求”来自原题：2%误差带、两题不同阻尼比、并联PID、第三题六种配置、第二题参数提交顺序。前置知识另列为建议，由自己标记是否熟悉。
3. 对照两页原文，选择前置知识或第一题的起点。可以先核对一项不熟悉的内容，不强制做完整测验。
4. 本次演示停在理解要求、找到方法出处、明确下一步的位置。以后需要自行计算、仿真、绘图的工作保留为计划；系统没有提供参数或设计结论。
5. 保存准备性回顾与下次起点。“已回顾某阶段”不表示题目或作业完成。

## 用户控制与恢复

- 模拟生成有短暂状态，可取消；修改文字会取消旧结果。没有自述时只给自检问题，不代写收获。
- 原生关闭前保存草稿与PDF页码。按板块和轮次保存回顾，早前草稿可恢复。
- 切换保留当前小步与书签；继续同块的暂停轮次不重复建轮次。
- 本地记录和主动邀请独立控制，默认关闭；仅记录StudyPet内材料操作，不监测其他窗口，不判断专注或掌握。
- 课堂示例自述需主动点击，会标注演示填写，不覆盖已有文字。
- 任务页的“管理全部任务”可切回和管理旧任务。课堂工具模拟材料失效后，可以重新打开本地材料，页码仍保留。

## 开发与材料

原PDF、99张分页图、逐页文字及来源哈希在 `renderer/study/materials/`。作业字体映射会造成中文提取乱码，本包文字、公式、图1与提交约束已对照原件校正；图片显示原页。

`study/case-plan.cjs` 定义模拟计划和验证；`case-actions.cjs` 处理候选及用户操作；`engine.cjs` 管理模块、书签、轮次、回顾；`renderer/study/cases.js` 展示流程。真实API框架仍保留，生产host明确设置 `networkEnabled:false`。

运行 `npm run test:study` 做行为回归，或 `npm run test:cases` 检查两个案例。未来恢复真实模型时，需要将其输出接入相同结构并重新验证引用、响应质量与用户确认流程。当前模拟不代表真实模型效果，也不是学习成效研究。
