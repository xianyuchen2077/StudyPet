# StudyPet 简短试玩指南

当前为 **2.4.0 两个材料案例模拟版**。不调用API、不需要密钥，所有模拟建议都有标记。详细步骤见 [两个材料案例](material-cases.md)。

运行完整Windows包中的 `StudyPet.exe`，或源码目录的 `StudyPet.cmd` / `npm start`。关闭面板保留桌宠；双击桌宠重开，右键退出。

- **学习课件**：选择HCI课件 → 模拟拆解 → 修改七块大纲 → 选择HTA并确认 → 看第61–64页 → 写解释和疑问 → 模拟整理 → 自己确认保存。演示只推进一块，其余待学内容保留。
- **梳理作业**：选择Homework 7 → 模拟拆解 → 核对要求 → 自检前置知识 → 选择第一题的准备步骤 → 记录下一步。演示止于知道如何开始，不生成参数或仿真答案。
- **共同规则**：大纲确认后才成为任务；模块切换不自动开始；候选不自动成为自己的理解；保存回顾不表示掌握或完成总任务。下一步另行加入计划。
- **恢复**：输入、模块书签和小步选择会暂存，关闭前等待保存。反馈按板块保留历史。任务页可进入“管理全部任务”切回旧任务。
- **演示工具**：示例自述需主动填入并带标记，不覆盖已有文字。设置底部保留情境重置、保存失败和材料失效恢复工具，重置前说明范围。

默认数据仍在 `%APPDATA%/StudyPet-OS-Demo`，旧资料保留。录制和测试使用独立资料目录，不改变用户数据。本版不消耗API额度。
