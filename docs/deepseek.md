# DeepSeek 与元认知学习辅助

> 此文保留2.3版接口配置说明。当前2.4版停用真实API，使用模拟建议；试玩见 [两个材料案例](material-cases.md)，无需配置密钥。

StudyPet 2.3 在现有桌宠和学习原型中加入可选的 DeepSeek 接口。它帮助用户明确目标、观察自己当前的理解、决定下一步；是否提升学习专注或学习成绩，仍需真人研究验证。

## 先配置

从项目目录运行 `npm start`，或双击 `StudyPet.cmd`。在学习面板右上角打开 **设置 → DeepSeek 辅助**，选择 DeepSeek API，填写你自己的 API Key，保存设置。默认模型为 `deepseek-flash`，也可选择 `deepseek-v4-pro`。模型名称依据 2026-11-15 官方文档；未来更名时可在 `study/ai-settings.cjs` 更新。

密钥只在本机填写。勾选安全保存时，主进程使用 Electron `safeStorage` 加密，保存到当前用户资料目录的 `study-ai.json`，不会写入源码或学习数据。若系统加密不可用，可取消保存，仅在本次会话使用。空白密钥沿用已配置值；“清除本机密钥并停用”会切回本地模式。每位组员分别配置自己的密钥。

配置不会自动联网。“确认发送这一次”才会调用接口，可能产生 DeepSeek API 费用。程序不自动重试，不提供后台自动上传。

## 怎样使用

### 开始前：我想弄清什么

点击“帮我找个起点”，写一句学习意向，例如“想弄清 TCP 三次握手，能背顺序但说不清为什么需要三次”。已有基础和起步困难均可不填。请 DeepSeek 拆小后，会看到本次发送文字，确认发送即可。

模型返回一个小目标、2–4 条有顺序的行动和检验方式。目标、首步和检验方式可以修改。“再拆小”和“换个起点”在已配置 API 时可再次请求。点击“就从这一步开始”只确认首步，后续步骤仍是候选，要逐条加入。也可手写，或展开离线操作系统示例；离线内容有明确标注。

只有勾选内置材料时才使用线程资源图解和自测。其他学科使用自己的教材、笔记或练习；StudyPet 保留材料名称与位置，不读取文件。需要先确认自己的材料已找到，才开始学习。

### 学习中：我正在做什么，怎么知道懂了

学习页持续展示“我想弄清什么、我现在做什么、我如何检验”。检验方式可以改写，例如“合上图解，解释普通全局变量和线程栈分别属于谁”，而不是只写“看完了”。

点击“阶段自检”，先用自己的话解释一句，可以直接写“还说不清”。DeepSeek 可以归纳这段解释、保留疑问、给一个自检问题和策略建议。没有自述也可以只请求问题，程序会阻止模型凭空代写已经学会的内容。阶段自检不会结束当前学习轮次。

### 结束后：我改变了什么判断

结束一轮后可以进入复盘，也可跳过。对照原目标写收获、未解决点和下一步意向，再请 DeepSeek 整理。模型候选和自己的原稿分开显示；可以不用、修改，或采用候选填回编辑区。之后仍要点击“只保存回顾”。下一步另行加入计划，不自动开始学习，不自动标记任务完成或知识掌握。

阶段回顾和结束复盘可以分别保存，历史保留。

## 发送内容与失败处理

- 每次预览只包含当前学习意向、用户填写的基础与困难，或当前任务、眼前步骤、检验方式和这次复盘文字。复盘时过程线索默认不发送；可以逐条勾选有效线索，最多 8 条。来源会注明预置或模拟，观察和用户解释分开。
- 不上传全部历史、截图、桌面活动、文件内容或其他窗口信息。模拟记录许可与 API 发送是两回事。
- 模型等待时可以继续学习、取消、暂停和关闭。修改原稿、切换页面或关闭窗口会取消在途请求；迟到或过期建议不能覆盖新稿。
- 断网、密钥错误、余额不足、限流、45 秒超时、空 JSON、格式错误和截断均显示明确提示；原稿保留，可手写或手动重试。取消不能保证撤销服务端已经产生的计费。
- AI 不能从切换次数、耗时或用户没回复推断专注或掌握，输出也不作为学习效果的客观证据。

## 开发入口

- `study/ai-contract.cjs`：输入白名单、元认知提示词与输出结构校验。
- `study/ai-settings.cjs`：密钥加密、设置保存与仅会话密钥。
- `study/ai-service.cjs`：固定官方地址，Chat Completions，关闭 thinking，JSON mode，输出上限 1600 token，超时、取消与错误归类。
- `study/ai-ipc.cjs`：仅学习面板可用的 IPC；按当前任务筛选有效过程线索。
- `renderer/study/ai-assist.js`：独立设置、发送预览和请求状态；`panel.js` 连接三处学习流程。
- `engine.cjs`：只接收通过结构与版本校验的候选，正式任务和回顾仍经用户确认。

无需新增依赖。运行 `npm run test:study` 检查原有与新增行为，或 `npm run test:ai` 仅检查接口框架。HTTP 自动化测试使用假密钥和本地服务器，不消耗 API 额度。真实服务的鉴权、余额、网络可达性和中文建议质量，需要配置有效密钥后再作最终联调。

接口依据：[首次调用](https://api-docs.deepseek.com/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。
