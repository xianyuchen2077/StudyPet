# StudyPet 学习桌宠原型

完整项目说明见 [README](README.md)，试玩步骤见 [简短指南](docs/guide.md)。

当前版本在原有“目标—小步—自检—回顾”学习流程之外，加入了**新手引导**和**前台窗口专注提醒**：

- **新手引导**：首次启动首页只展示两份演示材料（先 HCI 课件、再控制作业），每个案例要完成「采用大纲 → 完成一小步 → 保存回顾」三步；页面上有高亮框+气泡指出下一步该点哪里。两个都走完后点「开始正式使用」，首页才进入自己的学习任务，演示材料收进「我的任务 / 新手教程案例」。**也可以随时「跳过引导，直接使用」**，已做内容保留。进度存本地，设置页可「重新走一遍」（不删任务与回顾）。

- 主进程通过 `study/focus-sampler.ps1` 每 2 秒读取前台窗口的进程名和标题（不截图、不读页面内容）；
- `study/focus-rules.cjs` 判定抖音、B站等娱乐页面，`study/focus-watch.cjs` 负责连续停留阈值、冷却与重新计时；
- 达到阈值后桌宠弹出「我回来了 / 再给我 5 分钟 / 这次不用」，回应写入本地记录；
- 结束学习时，回顾页先显示本轮被提醒次数，并问“是什么把你带走的”，再接原有的自检问题。

设置页可整体关闭监测；「模拟一次娱乐页面提醒」可在不打开娱乐网站的情况下查看效果。所有记录与助手建议仍为本地演示，不调用真实模型。
